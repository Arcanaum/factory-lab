# Vision

A tiny, dependable set of text helpers that runs anywhere JavaScript runs.

## Goals
- Correct for empty text, accents, emoji and long input.
- Every function is tested and described in the README.

## Target users
- Developers who need a few small text helpers.

## Principles
- No dependencies, no network, no files, no state.
- Small functions with plain names.

## Out of scope
- Tracking, analytics, accounts, web pages, command line tools.
- Anything that needs a key, a service or a download.

## Quality bar
- Tests first. The whole test run passes.

## Protected areas
- `.github/**`
- `package.json`
- `AGENTS.md`
- `LICENSE`
- licensing
